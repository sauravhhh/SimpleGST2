What it does

SimpleGST2 is a quick GST calculator for Indian tax slabs. Type an amount, pick whether it is the taxable value or the total MRP, choose the GST rate, and the taxable value, GST amount and total update instantly.

How it calculates

Taxable Value — GST is worked out on the amount and added on top.

GST = Taxable Value × Rate ÷ 100
Total = Taxable Value + GST

Total MRP — the price already includes GST, so the calculator works backwards to find the taxable value inside it.

Taxable Value = MRP ÷ (1 + Rate ÷ 100)
GST = MRP − Taxable Value
